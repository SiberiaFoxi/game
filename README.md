# S.T.A.L.K.E.R.: Тень Чернобыля — тотальная конверсия для GTA San Andreas

**stalker_mod.asi** — мод-конверсия, превращающий GTA San Andreas в выживание
в Зоне: пустой и тихий мир, редкие опасные люди, орды мутантов, радиация,
аномалии, артефакты, противогаз, выбросы, фракции, инвентарь и торговля.

* **Целевая игра:** GTA San Andreas **1.0 US** (compact exe,
  14 383 104 байта). Другие версии не поддерживаются.
* **Формат:** ASI/DLL, загружается любым ASI-загрузчиком (dinput8.dll).
* **Сборка:** CMake + Visual Studio 2022 (Win32), C++20.
* **База адресов и структур:** [gta-reversed](https://github.com/gta-reversed/gta-reversed) —
  проект полного реверса GTA SA. Все 73 игровых адреса, используемые модом,
  взяты из его исходников и проверяются скриптом `tools/verify_addresses.py`
  (текущий статус: **100% подтверждены**).

## Быстрый старт

1. **Установите инструменты** (один раз):
   * [Visual Studio 2022 Community](https://visualstudio.microsoft.com/) с компонентом
     «Разработка классических приложений на C++» (включая x86-инструменты);
   * [CMake](https://cmake.org/download/) (или используйте встроенный в VS2022);
   * [Git для Windows](https://git-scm.com/download/win).
2. **Положите** `run_stalker.bat` и папку проекта в папку игры
   (или укажите путь к игре в переменной `GAME_DIR` внутри bat-файла).
3. **Запустите** `run_stalker.bat`. Скрипт:
   * проверит наличие `gta_sa.exe` (и предупредит, если версия не 1.0 US);
   * склонирует [gta-reversed](https://github.com/gta-reversed/gta-reversed)
     (база адресов; сборка самого gta-reversed **не требуется**);
   * соберёт мод: `cmake -B build -A Win32` + `cmake --build build --config Release`;
   * скопирует `stalker_mod.asi` и ASI-загрузчик (`dinput8.dll` из
     `gta-reversed/contrib/plugins.zip`) в папку игры;
   * скопирует конфиги и модели в `<игра>/STALKER_MOD/`;
   * запустит `gta_sa.exe`.
4. Аргументы: `--no-build` (запуск без сборки), `--no-run` (только сборка).

При любой ошибке скрипт печатает понятное сообщение и ждёт нажатия клавиши.

## Ручная установка

```bat
git clone https://github.com/SiberiaFoxi/game
cd game
cmake -B build -A Win32
cmake --build build --config Release
:: Копируем в папку игры:
copy build\Release\stalker_mod.asi  "<папка GTA SA>\"
copy scripts\*.cfg                  "<папка GTA SA>\STALKER_MOD\"
xcopy /y /e /i assets\models        "<папка GTA SA>\STALKER_MOD\models"
:: ASI-загрузчик (если ещё не стоит): dinput8.dll из
:: gta-reversed\contrib\plugins.zip — распаковать в папку игры
```

Проверка синтаксиса исходников на Linux/без Windows SDK:

```bash
tools/check_syntax.sh                      # или:
cmake -B build-check -DSTALKER_SYNTAX_CHECK=ON && cmake --build build-check
```

Сверка адресов с клоном gta-reversed:

```bash
python3 tools/verify_addresses.py ./gta-reversed
```

## Что меняется в игре

### 1. Людей почти нет (10–15% от исходного населения)

* плотность пешеходов снижается до `0.10–0.15` (`CPopulation::PedDensityMultiplier`
  — тот же механизм, что использует сам gta-reversed в `CutsceneMgr`);
* случайные копы и бандиты отключены (`m_bDontCreateRandomCops`,
  `m_bDontCreateRandomGangMembers`);
* редкие люди — только NPC фракций (максимум 2–3 вокруг игрока): сталкеры,
  бандиты, военные, монолит, свобода, долг. Они опасны и вооружены.
* большая часть карты — пустая и тихая.

### 2. Все миссии отключены

Мир — только песочница выживания и свободное исследование. Не запускаются:
сюжетные и побочные миссии, миссии фракций, гонки, школы (вождение/авиация/
лодки/мото), угоны, доставки, убийства, ограбления, телефонные звонки.

Технически: все миссии стартуют командой скриптового движка `LAUNCH_MISSION`,
которая создаёт `CRunningScript` с флагом `m_ThisMustBeTheOnlyMissionRunning`
(см. `gta-reversed/source/game_sa/Scripts/Commands/MissionCommands.cpp`,
`LoadAndLaunchMissionInternal`). Мод перехватывает `CRunningScript::Process`
(0x469F00): миссионные и внешние скрипты (телефон, гонки, школы) мгновенно
завершаются через `ShutdownThisScript`. Остальные системы игры работают как
обычно.

### 3. Мутанты — 85–90% населения

Мутанты спавнятся повсеместно: в городах, лесах, пустыне, у воды, в тёмных
переулках (ночью в городах их больше). Агрессивны и территориальны — атакуют
игрока при обнаружении. Типы различаются силой, скоростью, здоровьем и уроном.

Спавн выполняется движковой функцией `CPopulation::AddPed` (0x612710) — той
же, что используется скриптовой командой `CREATE_CHAR`. Агрессия — движковый
ИИ на ненависти (`CAcquaintance` + `CEventAcquaintancePedHate`, как в читовом
режиме «Mayhem» в оригинале). Прямой урон атак мутантов добавляется поверх
движкового ИИ.

## Системы выживания

### Радиация
* Зоны задаются в `zones.cfg` (Area 69, «Большое ухо», химзавод Easter Basin,
  нефтепромыслы, дамба Шерман, карьер, свалка Лос-Сантоса, гора Чилиад);
* накопление дозы с учётом защиты; урон при дозе выше порога;
* счётчик Гейгера — щелчки динамика, частота зависит от интенсивности;
* противогаз даёт 85% защиты, фильтр изнашивается быстрее в сильном поле.

### Аномалии
* Типы: гравитационная «Воронка» (швыряет вверх), электро «Электра»
  (мощный разряд), термо «Жарка» (непрерывный ожог), химическая «Кисляк»
  (добивает радиацией);
* 12 полей аномалий размещены детерминированно (одинаково при каждом запуске);
* визуализация — цветные кольца-маркеры (фиолет/синий/оранж/зелёный);
* детекторы: **«Отклик»** (сигналит у аномалий) и **«Велес»** (показывает
  аномалии и артефакты с направлением и дистанцией на HUD).

### Артефакты
* 7 типов: Медальон, Вспышка, Лунный свет, Колобок, Бусы «мамы» (реген HP,
  сопротивление радиации, выведение дозы, прибавка к макс. HP);
* появляются возле аномалий, возрождаются со временем; после выброса — буйство;
* ношение до 5 одновременно (эффекты складываются).

### Противогаз
* предмет + ресурс фильтра (10 минут); при выработанном фильтре защита
  пропадает, HUD предупреждает;
* визуальный оверлей (затемнение краёв экрана);
* запасные фильтры ставятся автоматически.

### Фракции (людей крайне мало)
Сталкеры (торговцы, нейтралы), Бандиты (враждебны), Военные (враждебны),
Монолит (враждебны), Свобода и Долг (нейтральны) — все с оружием.

### Выброс
* периодически (20–30 минут) — красное небо (покраска `CTimeCycle::
  m_CurrentColours` каждый кадр), тряска камеры, тревога;
* вне укрытия (интерьер/крыша) — смертельный урон; весь мир на открытом
  воздухе гибнет;
* после выброса аномалии «рождают» новые артефакты.

### Инвентарь и торговля
* вес (лимит 50 кг), деньги — родная система GTA (`CPlayerInfo::m_nMoney`);
* аптечки, бинты, антирад, еда (реген), фильтры, противогаз, детекторы;
* торговля у сталкеров-торговцев (клавиша `T`): покупка/продажа (Tab),
* подбор артефактов — подойти вплотную.

### Сохранение
Сейвы GTA SA **не модифицируются** — полная совместимость с обычными
сохранениями. Прогресс мода хранится отдельно в
`STALKER_MOD/stalker_save.dat` (автосохранение каждые 30 секунд, `F9` —
вручную).

## Управление и читы

| Клавиша | Действие |
| --- | --- |
| `I` | инвентарь (Enter — использовать, U — выбросить) |
| `T` | торговля у торговца (Tab — купить/продать) |
| `F9` | сохранить прогресс мода |
| `F10` | отладочный экран |

**Читы** (набираются с клавиатуры, как обычные читы GTA):

```
STALKERHEALTH     — полное здоровье
STALKERARMOR      — полная броня
STALKERARTIFACT   — случайный артефакт
STALKERRAD        — обнулить дозу радиации
STALKERWEATHER    — вызвать выброс
STALKERDETECTOR   — получить детектор «Велес»
STALKERNOMUTANTS  — включить/выключить спавн мутантов
```

## Структура проекта

```
├── run_stalker.bat          # сборка + установка + запуск
├── CMakeLists.txt           # CMake (Win32 ASI + режим проверки синтаксиса)
├── src/
│   ├── Main.cpp             # точка входа ASI, порядок инициализации
│   ├── Hooking/Int3Hooks.*  # хуки через int3 + VEH (без зависимостей)
│   ├── Gta/                 # мини-SDK: адреса, структуры, обёртки функций
│   │   ├── GtaAddresses.h   # 73 адреса GTA SA 1.0 US (сверены с gta-reversed)
│   │   ├── GtaTypes.h       # CPed/CPlayerInfo/CRunningScript/... (раскладки)
│   │   ├── GtaFunctions.h   # cdecl/thiscall-обёртки
│   │   └── ModelLoader.*    # загрузка DFF/TXD в рантайме (RW + CTxdStore)
│   ├── Core/                # лог, конфиги, RNG, сейвы, клавиатура
│   └── Systems/             # 12 систем мода (мутанты, радиация, аномалии...)
├── scripts/                 # конфиги (копируются в STALKER_MOD) +
│   │                        # StalkerCommands.cpp — интеграция CommandParser
│   │                        # для сборки внутри gta-reversed
├── assets/models/           # сюда кладутся скачанные модели (см. README)
└── tools/                   # check_syntax.sh, verify_addresses.py
```

### Отношение к gta-reversed

[gta-reversed](https://github.com/gta-reversed/gta-reversed) — база проекта:

* **адреса и структуры** мода взяты из исходников gta-reversed и сверены
  автоматически (`tools/verify_addresses.py`, 100% совпадение);
* **точки входа** — те же функции, что реверсит gta-reversed (`Idle`,
  `CHud::Draw`, `CRunningScript::Process`, `CPopulation::AddPed`,
  `CStreaming::RequestModel`, события `CEventGroup`...);
* **скриптовая система** — при сборке мода *внутри* gta-reversed файл
  `scripts/StalkerCommands.cpp` регистрирует команды мода через их
  `CommandParser` (`REGISTER_COMMAND_HANDLER`) — CLEO-скрипты получают
  управление модом;
* самостоятельный `stalker_mod.asi` — независим и **не требует** сборки
  gta-reversed, но не должен грузиться одновременно с `gta_reversed.asi`
  (оба патчат одни функции — конфликт хуков).

Собрать gta-reversed (по желанию): см. их README (`python setup.py`,
Conan 2.x, CMake ≥ 4.2, VS2022).

## Совместимость и ограничения

* **Только GTA SA 1.0 US.** Проверка размера exe в bat-файле предупреждает.
* Не грузите одновременно с `gta_reversed.asi` или другими модами,
  хукающими `Idle`/`CHud::Draw`/`CRunningScript::Process` (CLEO, ASI-плагины
  типа SilentPatch — совместимы, т.к. не пересекаются с нашими функциями;
  при проблемах пишите в issues).
* Сейвы GTA SA полностью совместимы: мод не пишет в игровые сейвы.
* v1-ограничения (в разработке): 3D-модель противогаза на голове игрока
  (сейчас — оверлей + механика фильтров); кастомные анимации четвероногих;
  невидимость кровососа; продажа хвоста/лап мутантов; пси-эффекты
  контролёра (сейчас — прямой пси-урон); торговец-интерфейс без текста
  (латиница — шрифт SA не отображает кириллицу).
* Вердикт по производительности: все тяжёлые системы обновляются
  порциями (слайсинг), аномалии симулируются только рядом с игроком.
